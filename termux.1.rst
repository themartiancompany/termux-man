=============================
termux
=============================

--------------------------------------------------------------
The Android terminal
--------------------------------------------------------------
:Version: termux |version|
:Manual section: 1


Synopsis
========

termux *[options]*


Description
===========

Launches the Termux terminal
application.

The Termux application is a core
component of DogeOS.

Options
=======

-m method            Method to open the application.
                     It can be 'root'.


Application options
=====================

-h                   Display help.
-c                   Enable color output
-v                   Enable verbose output
